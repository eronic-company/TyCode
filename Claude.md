# Version Control

This project uses **Tiv**, not git. See global ~/.claude/CLAUDE.md for the full command reference.

- Stage: `tiv add <files>`
- Manual commit: `tiv com "message"`
- Versioned commit: `tiv rit`  (no message)
- Status: `tiv status`
- History: `tiv log`
- Push: `tiv publish`
- Pull: `tiv sym`
